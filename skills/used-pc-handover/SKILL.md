# 중고 PC 인수 정리

중고 PC를 받으면 **이전 소유자의 흔적이 그대로 남아 있다.** 라이선스, 설치 프로그램, 계정, 설정 전부다. 이걸 정리하지 않으면 몇 달 뒤 라이선스가 만료되거나, 정체 모를 프로그램이 백그라운드를 잡아먹거나, 아이가 쓸 PC에 관리자 권한이 열려 있게 된다.

순서가 있다. **라이선스 확인이 가장 먼저**인데, 그 결과에 따라 포맷을 할지 말지가 결정되고 예산도 달라진다.

## 작업 순서

### 1. 하드웨어가 광고와 일치하는지 확인한다

`설정 → 시스템 → 정보`에서 CPU, 램 용량과 속도, 그래픽카드, 저장소 용량이 한 화면에 나온다. 메인보드 모델명도 장치 이름 아래에 표시되는 경우가 있다.

여기서 다 나오면 CPU-Z는 필요 없다. 추가로 알 수 있는 건 램 채널 수와 바이오스 날짜 정도다.

**크리스탈디스크인포는 별도로 확인한다.** SSD 사용 시간과 건강도는 시스템 정보에 안 나오고, 이제 본인 물건이니 직접 볼 수 있다. 판독 기준은 `used-pc-listing-check` 스킬의 `references/photo-forensics.md`에 있다.

### 2. 윈도우 라이선스를 판정한다

**이 단계가 이후 계획 전체를 결정한다.**

`설정 → 시스템 → 정품 인증`

| 표시 | 판정 | 대응 |
|---|---|---|
| "디지털 라이선스로 정품 인증되었습니다" | 보드 귀속 정품 | 추가 지출 없음. 포맷해도 자동 인증 |
| "Microsoft 계정에 연결된 디지털 라이선스" | 판매자 계정 귀속 | 판매자에게 계정 분리 요청 |
| "제품 키로 정품 인증" | 키 확인 필요 | 키를 받아두고, 다른 PC에도 썼는지 확인 |
| **"볼륨 라이선스 정품 인증이 [날짜]에 만료됩니다"** | **KMS 우회. 정품 아님** | DSP 구매 필요 |
| "정품 인증되지 않았습니다" | 라이선스 없음 | DSP 구매 필요 |

### 볼륨 라이선스가 보이면 정품이 아니다

볼륨 라이선스(KMS)는 기업·학교가 대량으로 쓰는 방식이다. **개인 PC에 만료일과 함께 표시되면 우회 인증 도구를 쓴 것이다.**

- 180일마다 만료되고 재인증이 필요하다
- 만료 후에는 워터마크가 뜨고 개인 설정(배경, 테마)이 잠긴다
- 우회 도구는 보통 백신을 끄고 설치하며, 시스템에 스케줄러를 심는다

**아이가 쓸 PC라면 특히 정리해야 한다.** 몇 달 뒤 갑자기 워터마크를 보고 당황할 상황을 만들 필요가 없고, 우회 도구가 남아 있는 상태도 바람직하지 않다.

### 정품화 방법과 비용

| 방법 | 비용 | 포맷 필요 |
|---|---|---|
| 현재 설치된 에디션과 같은 DSP 구매 | Home 13~15만 / Pro 18~20만 | **불필요** (제품 키 변경만) |
| 다른 에디션 DSP 구매 | 위와 같음 | 필요 |

현재 Pro가 설치돼 있는데 Home 키를 넣으면 에디션이 안 맞아 거부된다. **5만원 차이와 재설치 수고를 비교해 판단하게 한다.**

가정용·아이용 PC에 Pro 기능(원격 데스크톱 호스트, 비트로커, 그룹 정책)은 쓸 일이 없다.

**만료일까지는 시간이 있다.** 급하지 않으므로 사용자가 원하면 나중으로 미뤄도 되지만, 만료 날짜를 명확히 알려주고 그 전에 처리하라고 한다.

### 3. 포맷 여부를 결정한다

**포맷을 권하는 이유들이다.**

- 이전 소유자가 무엇을 설치했는지 알 수 없다
- 계정과 개인 자료가 남아 있다
- 블로트웨어를 하나씩 지우는 것보다 빠르고 확실하다
- 아이에게 줄 물건이면 자료가 쌓인 뒤에 포맷하는 게 더 번거롭다

**다만 강요하지 않는다.** 사용자가 포맷을 원하지 않으면 프로그램 정리와 계정 분리로 대응한다. 그 경우 4번과 5번을 꼼꼼히 한다.

포맷할 경우 순서는 이렇다. 마이크로소프트 공식 사이트에서 미디어 생성 도구로 USB를 만들고, 설치 후 DSP 키를 입력한다. 그 다음 드라이버는 두 개만 깔면 된다(6번 참고).

### 4. 설치된 프로그램을 정리한다

`제어판 → 프로그램 및 기능`

목록과 판단 기준은 `references/cleanup-list.md`를 읽는다. 요약하면 세 부류다.

**한국 금융 보안 프로그램** — 은행·정부 사이트에서 강제로 깔리는 것들이다. 백그라운드에서 계속 돌면서 시스템을 느리게 하고, 키보드 입력을 가로채는 방식이라 아이 PC에 둘 이유가 없다. 열 개 가까이 깔려 있는 경우가 흔하다.

**제조사 유틸리티** — 오버클럭·팬 제어·바이오스 업데이트용이다. 일반 사용에는 필요 없고 광고성 알림을 띄운다.

**절대 지우면 안 되는 것** — Microsoft Visual C++ 재배포 패키지 전부. 게임과 프로그램이 이걸 쓴다. 지우면 뭔가 안 돌아간다.

### 5. 계정을 정리한다

**다른 사람(자녀, 지인)에게 넘길 물건이면 이 단계가 중요하다.**

`설정 → 계정 → 다른 사용자 → 계정 추가`로 **표준 사용자 계정**을 만든다. 관리자 계정은 관리하는 사람이 갖는다.

표준 사용자로 두면 함부로 프로그램을 설치하거나 시스템 설정을 바꾸지 못한다. 나중에 정리가 훨씬 쉬워지고, 악성 프로그램 설치 사고도 줄어든다.

**자녀용이면 윈도우 가족 기능**으로 사용 시간과 웹 필터를 설정할 수 있다.

판매자가 쓰던 계정은 자료를 확인한 뒤 삭제한다.

### 6. 드라이버를 정리한다

포맷했으면 두 개만 깔면 하드웨어가 다 정상 동작한다.

- **메인보드 제조사 사이트의 칩셋 드라이버** (모델명으로 검색)
- **그래픽카드 제조사(NVIDIA / AMD) 드라이버**

제조사 유틸리티 묶음은 깔지 않는다. 바이오스 업데이트가 필요하면 사이트에서 파일을 받아 직접 하는 게 더 안전하다.

**포맷하지 않았으면** 그래픽 드라이버를 최신으로 "클린 설치" 옵션으로 다시 까는 것을 권한다. 이전 소유자 환경에 맞춰진 설정이 남아 있을 수 있다.

### 7. 설정을 맞춘다

**램 속도.** 작업 관리자나 시스템 정보에서 확인한다. 표기 속도보다 낮게 나오면(예: 3200 램이 2133으로) 바이오스에서 XMP 또는 D.O.C.P를 켠다. 조립 상태로 받은 중고는 이게 꺼져 있는 경우가 흔하다. 내장그래픽 구성에서는 성능에 직접 영향을 준다.

**해상도와 주사율.** 모니터가 바뀌면 60Hz 기본값으로 잡히고, 해상도가 권장값이 아니면 화면 전체가 어색해진다. 사용자가 "버벅인다"거나 "글자가 이상하다"고 하면 여기를 먼저 본다.

**배율.** 아이가 쓸 PC면 125~150%가 눈에 편하다.

### 8. 남은 예산 항목을 정리한다

인수 후 추가로 들 수 있는 비용을 사용자가 알게 한다.

| 항목 | 비용 | 조건 |
|---|---|---|
| 윈도우 DSP | 13~20만 | 라이선스가 정품이 아닐 때 |
| 무선랜 어댑터 | 1~3만 | 보드에 Wi-Fi가 없고 유선 연결이 어려울 때 |
| 오피스 | 0원 | 학생은 Microsoft 365 Education 무료 또는 office.com 웹 버전 |
| 배터리 교체 (노트북) | 5~30만 | 열화됐을 때. 화면 크기에 따라 다름 |
| 파워 교체 | 5~10만 | 3년 이상 된 저가 파워는 몇 년 내 대상 |

**Wi-Fi 유무는 작업 관리자 성능 탭에서 확인한다.** Wi-Fi 항목이 없으면 보드에 무선랜이 없다. 저가 보드는 대부분 유선만 지원한다.

## 자주 나오는 상황

**"새로 받았는데 버벅인다."** 대개 소프트웨어 문제다. 확인 순서는 이렇다.

1. 윈도우 업데이트 직후인지 — 인덱스 재구성, 디펜더 검사, 텔레메트리가 몇 시간 돈다. 켜두면 가라앉는다
2. 작업 관리자에서 무엇이 잡아먹는지 — 디스크 활성 시간이 높은데 전송 속도가 낮으면 작은 파일 대량 처리 중이다
3. 해상도와 주사율이 모니터에 맞는지
4. 시작 프로그램에 불필요한 것이 있는지

**수치를 오독하지 않게 한다.** 유휴 상태에서 CPU 1~10%, 메모리 15~25%는 정상이다. 검색이나 프로그램 실행 순간 70~80% 찍는 것도 정상이다. NVMe가 20MB/s로 나오는 것도 순차 전송이 아닐 뿐 고장이 아니다.

**"오피스랑 한글도 깔려 있는데."** 라이선스가 아니라 설치 상태다. 중고 PC에서 정식 라이선스일 가능성은 낮고, 윈도우가 우회 인증이었다면 같은 경로일 확률이 높다.

학생이면 **Microsoft 365 Education이 무료**다. 학교가 라이선스를 보유하는지 행정실에 문의하라고 안내한다. 없어도 office.com 웹 버전이 무료다.

**한글(hwp)은 별개로 판단한다.** 학교나 직장에서 실제로 얼마나 쓰는지 확인한 뒤, 자주 쓰면 한컴독스 웹 버전(월 몇천원)이나 정식 구매, 거의 안 쓰면 무료 뷰어로 충분하다.

## 하지 말 것

**우회 인증 도구를 쓰는 방법을 안내하지 않는다.** 라이선스가 정품이 아니면 정식 구매 경로만 제시한다.

**포맷을 강요하지 않는다.** 권하되 사용자가 원하지 않으면 대안(프로그램 정리, 계정 분리, 키 변경)으로 처리한다.

**Visual C++ 재배포 패키지를 정리 목록에 넣지 않는다.** 이름이 반복돼서 중복처럼 보이지만 버전별로 다 필요하다.
