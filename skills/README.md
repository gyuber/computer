# PC 구매 스킬 모음

중고·신품 PC를 고르고, 판단하고, 인수하는 과정을 Claude 스킬로 정리한 것이다. 실제로 아이용 데스크탑 한 대를 구하면서 매물 스물여섯 건을 검토한 과정에서 나온 판단 규칙들을 담았다.

## 스킬 세 개와 사용 시점

구매는 세 단계로 진행되고, 각 단계에 스킬 하나가 대응한다.

```
방향 설정          →  매물 판단          →  인수 정리
pc-buying-brief       used-pc-listing-check   used-pc-handover
```

### 1. `pc-buying-brief` — 무엇을 살까

용도와 예산에서 목표 사양을 역산한다. 데스크탑과 노트북, AM4와 AM5 같은 플랫폼 선택을 결정하고, 다른 사람에게 공유할 브리프 문서를 만든다.

**쓰는 때:** "아이 컴퓨터 100만원으로 뭐 사지", "노트북이랑 데스크탑 중 뭐가 나을까"

핵심 판단은 **"업그레이드 권리에 얼마를 지불하는가"** 프레임과 오버스펙 반려다. 예산은 상한이지 목표가 아니다.

### 2. `used-pc-listing-check` — 이 매물이 좋은가

매물 스펙이나 사진을 받아 부품값 대비 가격, 탈락 규칙, 용도 정합성을 판단한다.

**쓰는 때:** 매물 스펙을 붙여넣거나 케이스 내부 사진·CPU-Z·크리스탈디스크인포 스크린샷을 올리면서 "이거 어때?"

하위 문서 세 개가 있다.

- `references/part-tiers.md` — 칩셋·CPU·램·SSD·그래픽카드·파워 등급표와 앵커 시세
- `references/photo-forensics.md` — 스크린샷 판독과 교차검증. **SSD 사용 시간으로 채굴 여부를 배제하는 추론**이 여기 있다
- `references/seller-questions.md` — 판매자에게 무엇을 어떻게 물을지

### 3. `used-pc-handover` — 받았는데 뭐부터

라이선스 검증, 블로트웨어 정리, 계정·드라이버 세팅을 순서대로 처리한다.

**쓰는 때:** "중고 PC 받았는데 뭐부터", "윈도우 정품 확인", "지울 프로그램 있어?"

핵심은 **볼륨 라이선스(KMS) 만료일이 보이면 우회 인증**이라는 판정과, 한국 금융 보안 프로그램 정리다.

- `references/cleanup-list.md` — 제거 대상과 절대 지우면 안 되는 것

## 설치

`skills/dist/`에 설치용 `.skill` 패키지가 있다. Claude 대화에 첨부하면 저장 버튼이 뜨고, 저장하면 이후 모든 대화에서 자동으로 발동한다.

프로젝트 지식에 넣거나 raw URL로 불러오는 방법도 있다. 자세한 내용은 `dist/README.md`를 참고한다.

## 설계 원칙

**가격을 하드코딩하지 않는다.** DRAM과 NAND 값은 주 단위로 움직인다. 스킬은 판단 구조와 규칙만 담고, 시세는 검색으로 조회하게 한다. 앵커 값에는 기준일을 붙여 참고용으로만 둔다.

**성능만 보고 판단하지 않는다.** 부품값보다 싸고 성능이 좋아도 메인보드 하나 때문에 사면 안 되는 매물이 있고, 오버스펙이라 값어치가 잠들어 있는 매물이 있다.

**판매자 설명과 실물을 대조한다.** 판매자는 자주 틀린다. 악의가 아니라 자기 물건을 정확히 모르는 경우가 대부분이다.

**완벽한 매물을 기다리게 만들지 않는다.** 좋은 매물은 며칠 안에 나간다. 신품 완제품 총액을 상한선으로 잡아두면 "이보다 나으면 진행"이라는 기준이 생긴다.

## 이 스킬들이 잡아낸 것들

실제 사례에서 나온 것들이다.

- **A320·B350 보드에 라이젠 5000번대** 조합 — 비공식 지원. 여러 매물에서 반복 발견
- **M.2 모양의 SATA SSD** — 표기만 보면 NVMe로 오인
- **볼륨 라이선스 우회 인증** — "윈도우 정품 설치"라고 광고된 매물에서
- **존재하지 않는 모델명** — "라이젠 5600XT", "RTX 3060 Ti"
- **SSD 사용 시간 681시간** — 1년 9개월 보유 대비 하루 1시간. 채굴 배제와 실사용량 확인이 동시에
- **바이오스 날짜와 구입일 일치** — 설명 전체의 신뢰도를 올린 근거

## 기준일

2026년 9월. 앵커 시세와 부품 세대 판단은 이 시점 기준이다. 시장 상황(램·SSD 대란)이 판단에 큰 영향을 주고 있으므로, 상황이 정상화되면 관련 전략을 재검토해야 한다.
