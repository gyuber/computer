# 사진·스크린샷 판독과 교차검증

판매자 설명은 자주 틀린다. 악의가 아니라 **자기 물건을 정확히 모르는 경우**가 대부분이다. 중고로 산 물건을 다시 파는 사람, 조립을 남에게 맡긴 사람은 램 용량조차 헷갈린다.

그래서 실물 증거를 설명과 대조하는 것이 이 판단의 핵심이다. 아래는 자료별로 무엇을 읽고 무엇과 맞춰보는지다.

## 크리스탈디스크인포

**중고 PC에서 가장 정보량이 많은 한 장이다.** 반드시 요청한다.

| 읽는 항목 | 판단 |
|---|---|
| 건강 상태 % | 95% 이상이면 양호. 90% 아래면 감점 |
| 사용 시간 | 실사용량의 직접 지표 |
| 사용 횟수 | 전원 인입 횟수. 사용 시간과 나눠보면 1회 평균 가동 시간이 나옴 |
| 총 쓰기량 | 수명(TBW, 보통 300TB) 대비 몇 %인지 |
| 인터페이스 | NVM Express면 NVMe, Serial ATA면 SATA |
| 전송 모드 | PCIe 3.0 x4 등. 보드·CPU 조합의 실제 동작 확인 |
| 일련번호 | 앞자리가 제조 연월인 경우가 많음 (예: 20241214 → 2024년 12월 14일) |
| 온도 | 40~55도 정상. 70도 이상이면 방열 문제 |

### 사용 시간으로 채굴을 배제한다

**이게 이 스킬에서 가장 값어치 있는 추론이다.**

SSD 사용 시간은 시스템 전원이 켜진 시간이므로, **그래픽카드가 가동될 수 있었던 시간의 상한**이다. 채굴은 24시간 수개월을 돌리는 작업이라 최소 2만 시간대가 나온다.

사용 시간이 5천 시간 이하면 채굴이 물리적으로 불가능하다. 중고 그래픽카드의 최대 리스크가 이 한 줄로 해소된다.

예시로, 보유 기간 3년(약 26,000시간)에 사용 시간 4,344시간이면 하루 평균 4시간이다. 게임용으로 적당히 쓴 물건이다. 보유 1년 9개월에 681시간이면 하루 평균 1시간으로, 거의 안 쓰인 물건이다.

**단, SSD를 중간에 교체했으면 이 논리가 깨진다.** SSD 제조일이 다른 부품보다 한참 늦으면 교체를 의심하고 물어본다.

### 사소한 항목

**예기치 않은 전원 손실 횟수**가 몇 회 있는 건 정상이다. 콘센트를 뽑거나 정전으로 꺼진 기록이다. 수십 회면 전원 환경이나 파워를 의심한다.

**매체/데이터 무결성 오류**가 한두 건 있어도 건강도가 높으면 문제 수준이 아니다.

## CPU-Z

탭별로 확인 항목이 다르다. 네 장을 요청한다.

### CPU 탭

- 모델명이 광고와 일치하는지
- **Cores와 Threads** — 6/6과 6/12는 완전히 다른 물건이다. 광고가 코어만 적었으면 여기서 확인
- Package (소켓) — AM4, AM5, LGA1151 등
- Code Name — Vermeer(5000번대), Matisse(3000번대), Cezanne(5000G APU) 등으로 세대 확인

### Mainboard 탭

- **Model** — 탈락 여부를 가르는 가장 중요한 한 줄
- Chipset / Southbridge — A520, B550 등
- **BIOS Date** — 교차검증의 핵심. 아래 체크리스트 참고
- Graphic Interface — 그래픽카드 슬롯의 실제 링크 속도. "PCIe 3.0 x16"으로 나오면 보드나 CPU가 3.0으로 묶고 있다는 뜻

### Memory 탭

- Size와 **Channel #** — "2 x 64-bit"면 듀얼채널
- **DRAM Frequency** — 표기 속도의 절반이 나온다. 1596MHz면 3200, 1333MHz면 2666
- CAS Latency

### SPD 탭

슬롯을 하나씩 선택해서 확인한다. 여기서 나오는 것이 특히 유용하다.

- 슬롯별 장착 여부 — 몇 개가 꽂혔는지 확정
- Module Manuf. / DRAM Manuf. — 삼성, 하이닉스 등
- Part Number — 정확한 모델. 나중에 증설할 때 필요
- **Week/Year** — 제조 주차. "26/23"은 2023년 26주차(6월말)

## 윈도우 시스템 정보

`설정 → 시스템 → 정보`. CPU-Z 없이도 상당 부분이 확인된다.

- 프로세서, 설치된 RAM과 **속도(MT/s)**, 그래픽카드, 저장소 용량
- 장치 이름 아래에 **메인보드 모델명**이 표시되는 경우가 있다
- Windows 사양의 **설치 날짜** — 포맷 시점. 판매자의 구입 시기와 대조

램 속도가 여기 표시되므로, CPU-Z 없이도 3200으로 도는지 확인할 수 있다.

## 윈도우 정품 인증 화면

`설정 → 시스템 → 정품 인증`. **이걸 확인하지 않으면 윈도우 값 13~20만원을 잘못 계산한다.**

| 표시 | 판정 |
|---|---|
| "디지털 라이선스로 정품 인증되었습니다" | 보드 귀속. 포맷해도 자동 인증. 값어치 있음 |
| "Microsoft 계정에 연결된 디지털 라이선스" | 판매자 계정에 묶임. 분리 요청 필요 |
| "제품 키로 정품 인증" | 키를 받아둬야 함. 판매자가 다른 PC에도 썼을 수 있음 |
| **"볼륨 라이선스 정품 인증이 YYYY년 MM월 DD일에 만료됩니다"** | **KMS 우회 인증. 정품 아님** |
| "정품 인증되지 않았습니다" | 라이선스 없음 |

### 볼륨 라이선스가 보이면 정품이 아니다

볼륨 라이선스(KMS)는 기업이나 학교가 대량으로 쓰는 방식이다. **개인 PC에 만료일과 함께 표시되면 우회 인증 도구를 쓴 것이다.** 180일마다 만료되고 재인증이 필요하며, 만료 후에는 워터마크가 뜨고 개인 설정이 잠긴다.

이 경우 윈도우 DSP를 별도로 예산에 잡는다. 현재 설치된 에디션이 Pro면 Pro 키를 사야 포맷 없이 키 변경만으로 해결된다. Home 키는 에디션이 안 맞아 재설치가 필요하다.

**"윈도우·오피스·한글 다 설치"를 세일즈 포인트로 내세우는 매물은 이 경우일 확률이 높다.** 정식이면 "DSP 정품 스티커 있습니다"처럼 구체적으로 말한다.

## 작업 관리자

성능 탭에서 확인한다. 스크린샷 요청이 부담스러운 판매자에게는 이것만 부탁해도 된다.

- **메모리** — 용량, 속도, **사용된 슬롯(1/2, 2/4 등)**. 램 개수 확정에 가장 확실
- 디스크 — 종류가 SSD(NVMe)인지 SSD인지 HDD인지
- 이더넷 / Wi-Fi — **Wi-Fi 항목이 없으면 무선랜이 없는 보드다**
- GPU — 모델명과 온도

### 성능 수치를 오독하지 않는다

사용자가 "버벅인다"며 수치를 보여줄 때가 있다. 정상 범위를 알려준다.

- 유휴 상태에서 CPU 1~10%, 메모리 15~25%는 정상
- 검색이나 프로그램 실행 순간 CPU가 70~80% 찍는 것은 정상
- **디스크 활성 시간이 50% 이상인데 전송 속도가 20MB/s대**면 작은 파일을 대량 처리하는 중이다. 윈도우 업데이트 직후의 인덱스 재구성, 디펜더 검사, 텔레메트리가 원인이고 시간이 지나면 가라앉는다
- NVMe가 20MB/s로 나오는 게 고장이 아니다. 순차 전송이 아닐 뿐이다

버벅임의 원인이 하드웨어가 아니라 **해상도·주사율 설정**인 경우도 흔하다. 모니터가 바뀌면 60Hz 기본값으로 잡히고, 해상도가 권장값이 아니면 화면 전체가 어색해진다.

## 케이스 내부 사진

### 요청 방법

측면을 열고 **정면에서 수직으로** 찍어야 한다. 유리 너머 비스듬한 각도로 찍으면 반사와 각도 때문에 정보가 묻힌다.

사진 한 장에서 확인 가능한 것들이다.

| 항목 | 위치 |
|---|---|
| 메인보드 모델명 | PCIe 슬롯 위, 칩셋 방열판, 램 슬롯과 CPU 사이. 그래픽카드에 가리면 후면 I/O 백패널 |
| 램 개수 | CPU 쿨러 오른쪽 세로 슬롯. 타워형 쿨러가 가리면 위에서 비스듬히 한 장 더 |
| SSD 방식 | 보드에 납작하게 누운 막대 = M.2 / 케이블 두 개 달린 네모 = SATA |
| 그래픽카드 모델 | 측면 또는 하단 스티커 |
| 파워 브랜드 | 하단 쉬라우드 안. 별도 사진 필요 |

### 사진에서 읽는 상태

**먼지가 관리 상태를 말해준다.** 3년 된 PC인데 쿨러 핀 사이가 깨끗하면 관리가 됐거나 사용량이 적다. 크리스탈디스크인포 사용 시간과 대조하면 확실해진다.

**케이블 정리가 안 된 것은 오히려 개인 조립의 신호다.** 업자는 선정리를 세일즈 포인트로 삼는다. 어설픈 설명과 정리되지 않은 케이블은 업자가 아니라는 정황이 된다.

**PCIe 보조전원 케이블 개수**로 그래픽카드 등급을 짐작할 수 있다. 8핀 하나면 중급 이하, 두 개 이상이면 고전력 카드다.

## 설치된 프로그램 목록

`제어판 → 프로그램 및 기능`. 이전 소유자의 사용 이력이 드러난다.

- **한국 금융 보안 프로그램 다수** — 은행·정부 사이트를 쓴 일반 사용자. 채굴이나 서버 용도가 아니라는 정황
- **채굴 소프트웨어**(NiceHash, PhoenixMiner, T-Rex, lolMiner 등) — 발견되면 즉시 패스
- **오피스·한글이 세일즈 포인트로 설치돼 있음** — 라이선스가 불분명할 가능성. 윈도우 인증 상태와 같은 경로일 확률이 높다
- 제조사 유틸리티(기가바이트 APP Center, ASUS Armoury Crate 등) — 보드 제조사 확인에 보조 근거

## 판매자 거래 내역

당근 등에서 프로필 거래 내역을 볼 수 있다. 확인 가치가 있다.

- **거래 이력과 후기가 있으면** 신규 사기 계정이 아니다
- **판매자가 그 PC를 언제 얼마에 샀는지** 나오는 경우가 있다. 호가의 근거를 알 수 있고, 손해를 보며 파는 상황이면 협상 여지가 있다
- 짧은 보유 기간에 되파는 패턴이면 업자가 아닐 가능성이 높다. 반대로 PC를 여러 대 파는 계정이면 업자다

## 교차검증 체크리스트

**설명과 실물이 어긋나는 지점을 찾는다.** 하나라도 안 맞으면 다른 항목도 재확인한다.

| 대조 | 확인 내용 |
|---|---|
| BIOS 날짜 ↔ 주장 구입일 | "2023년 9월 구입"인데 바이오스가 2023년 8월이면 조립 시점 그대로다. 일치하면 설명 전체의 신뢰도가 올라간다 |
| 램 제조 주차 ↔ "몇 개 추가했다" | 슬롯 2·4가 2023년 26주, 슬롯 1·3이 2024년 2주면 "원래 16GB에 8GB 두 개 추가" 설명과 정확히 맞는다 |
| SSD 사용 시간 ↔ "거의 안 썼다" | 보유 기간으로 나눠 하루 평균을 계산한다 |
| SSD 제조일 ↔ 다른 부품 세대 | 한참 늦으면 교체를 의심 |
| 윈도우 설치 날짜 ↔ 판매자 구입일 | 사자마자 포맷했다는 설명과 맞는지 |
| 그래픽카드 출시일 ↔ 채굴 종료 시점 | 2022년 9월 이후 출시면 채굴 불가능 |
| 광고 표기 ↔ 실측 | 램 32GB 표기인데 SPD에 한 개만 보이면 재확인 |

### 어긋남을 발견했을 때

**즉시 사기로 단정하지 않는다.** 판매자가 자기 물건을 모르는 경우가 훨씬 흔하다. 다만 **가격에 반영하고**, 나머지 항목도 확인 대상으로 올린다.

램 용량이 광고와 다르게 나오면 협상 명분이 확실하다. 판매자 실수이므로 무리한 요구가 아니다.
