## 플랫폼 비교 틀

### 세 줄로 정리한다

플랫폼 선택은 이 표 하나로 판단이 끝난다. 발생 확률이 낮은 줄에만 신규 플랫폼이 우위인 경우가 대부분이다.

| 실제로 일어날 일 | 확률 | 구형 플랫폼(AM4 등) | 신규 플랫폼(AM5 등) |
|---|---|---|---|
| 램 추가 | 높음 | 저렴 (DDR4) | 비쌈 (DDR5), 리스크 있음 |
| 그래픽카드 추가 | 중간 | 가능 | 가능 |
| CPU 교체 | **낮음** | 제한적 | 넓음 |

가벼운 용도에서 CPU가 부족해질 상황은 거의 오지 않는다. 사용자가 이미 몇 년 된 CPU를 쓰면서 "충분하다"고 느끼고 있다면, 그것이 이 용도에서 CPU 성능이 이미 과잉이라는 증거다.

### PCIe 세대는 대개 무의미하다

신규 플랫폼의 PCIe 5.0, 구형의 4.0 같은 차이는 중급 그래픽카드에서 몇 % 수준이다. 그리고 **CPU가 지원하지 않으면 보드가 지원해도 낮은 쪽으로 동작한다.** 예를 들어 라이젠 5000G 시리즈 APU는 PCIe 3.0만 지원하므로, B550 보드를 써도 4.0이 쓰이지 않는다.

이 경우 상급 보드를 고를 이유가 사라지므로, 보드 등급을 낮춰 예산을 아낄 수 있다.

### 예산 계산 예시 (2026-09 기준)

같은 용도를 두 플랫폼으로 맞추면 차이가 이렇게 벌어진다.

| 부품 | AM4 (5600GT) | AM5 (8600G) |
|---|---|---|
| CPU | 17만 | 26만 |
| 메인보드 | 12만 | 17만 |
| **램 32GB** | **DDR4 약 38만** | **DDR5 약 70만** |
| NVMe 1TB | 20만 | 20만 |
| 파워+케이스 | 11만 | 11만 |
| **합계** | **약 98만** | **약 144만** |

램 하나가 46만원 차이를 만든다. **DDR5 시기에는 플랫폼 논쟁이 아니라 예산 문제가 된다.**

## 램 전략

### 램값이 높은 시기의 슬롯 전략

16GB 한 개와 8GB 두 개의 값이 비슷할 때가 있다. 이때는 **16GB 한 개**가 낫다.

| | 8GB × 2 | 16GB × 1 |
|---|---|---|
| 지금 | 듀얼채널 (내장그래픽에 유리) | 싱글채널 |
| 나중에 32GB로 | 두 개 다 버려야 함 | **하나만 추가하면 완성** |

지금 듀얼채널을 포기하는 대가로, 나중에 하나만 추가해 32GB 듀얼채널이 완성된다. 값이 내려간 뒤에 사면 총 지출이 줄어든다.

**단 두 가지 조건이 있다.**

첫째, **내장그래픽을 쓰면 싱글채널 손실이 크다.** 내장그래픽은 시스템 램을 그래픽 메모리로 쓰므로 성능이 60~70%로 떨어진다. 외장 그래픽카드가 있으면 자체 VRAM을 쓰므로 영향이 거의 없다.

둘째, **DDR5는 이 전략이 덜 안전하다.** 채널당 2개(2DPC) 구성에서 속도를 낮춰야 하는 경우가 많고, 다른 생산 시기 모듈을 섞으면 EXPO를 못 쓰거나 부팅이 안 될 수 있다. 실패하면 기존 램을 팔고 키트를 새로 사야 한다. DDR4는 훨씬 관대하다.

### 램을 한 개만 꽂을 때

**슬롯 위치가 정해져 있다.** 보통 CPU에서 두 번째 슬롯(A2 또는 DIMM2)이고 메인보드 설명서에 표시돼 있다. 조립을 맡길 때 "나중에 하나 더 추가할 예정이니 단독 장착 권장 슬롯에 넣어주세요"라고 하면 된다.

**모델명을 적어둔다.** 나중에 추가할 때 같은 제조사·같은 모델로 맞추는 게 안전하다.

### 용량 판단

| 용도 | 적정 |
|---|---|
| 문서, 웹, 영상 시청, 교육용 프로그래밍 | 16GB |
| 위 + 라이트 게임 | 16GB (32GB면 여유) |
| 영상 편집, 대규모 개발, 가상머신 | 32GB 이상 |

**가벼운 용도에 32GB는 과잉이다.** 램값이 높은 시기에는 특히 그렇다. 예산의 상당 부분을 안 쓰는 용량에 쓰게 된다.

## 내장그래픽 대 외장그래픽

### 내장그래픽으로 충분한 경우

문서, 웹, 유튜브·영상 시청, 교육용 프로그래밍(엔트리, 스크래치), 가벼운 게임까지는 최근 내장그래픽으로 된다.

| 내장그래픽 | 수준 |
|---|---|
| Vega 7 (라이젠 5000G) | 마인크래프트 기본 플레이. 쉐이더·모드팩은 어려움 |
| Radeon 760M/780M (라이젠 8000G) | Vega 7보다 확실히 위. 라이트 게임 여유 |
| Radeon 2CU (라이젠 7000/9000 일반) | 화면 출력 수준. 게임 불가 |
| Iris Xe (인텔 11세대 이상) | Vega 7과 비슷하거나 소폭 위 |

**G 또는 GT가 안 붙은 라이젠은 내장그래픽이 없다.** 5600, 5600X, 5700X3D, 3700X 등은 화면 출력조차 안 되므로 그래픽카드가 필수다. 부품 셋이나 반본체를 계산할 때 반드시 확인한다.

### 외장그래픽이 유리한 경우

**중고 시장에서는 저렴한 외장 그래픽카드가 비싼 내장그래픽 구성을 이긴다.** RTX 4060은 760M보다 4~5배 빠르다. 즉 5600 + 중고 RTX 4060 조합이 8600G 내장그래픽 구성보다 저렴하면서 게임 성능이 훨씬 높은 경우가 흔하다.

### 나중에 추가하는 경로

내장그래픽으로 시작하고 부족해지면 그래픽카드를 추가하는 것이 합리적인 경우가 많다. **필요해지는 시점에 그때 시세로 사면 되고**, 미리 중고 구형 카드를 살 필요가 없다.

이 경로를 쓸 때 확인할 것은 PCIe 슬롯과 파워 용량 여유다. 500W 이상이면 중급 카드까지 대응된다.

## 노트북 판단

### 단 하나의 질문

**실제로 들고 다닐 일이 있는가.** 없으면 데스크탑이다.

집에서만 쓸 거라면 노트북은 같은 돈에 성능이 낮고 확장이 막힌 선택이다.

### 노트북의 구조적 한계

| 항목 | 데스크탑 | 노트북 |
|---|---|---|
| 램 확장 | 가능 | 온보드 모델은 불가 |
| 그래픽카드 추가 | 가능 | 불가 |
| CPU 교체 | 가능 | 불가 |
| 배터리 | 해당 없음 | 4~5년 뒤 열화 |
| 수리 | 부품 교체 | 전문 수리, 비용 큼 |
| 파손 위험 | 낮음 | 있음 |

**램이 온보드면 산 사양 그대로 끝까지 쓴다.** "오래 쓰며 업그레이드"라는 목표와 정면으로 어긋나므로, 그 요구가 있으면 노트북을 권하지 않는다.

### 기업용 중고 노트북

HP, 레노버 ThinkPad, 델의 비즈니스 라인은 예외적으로 유리하다.

- **윈도우 OEM 라이선스가 메인보드 펌웨어에 있어** 포맷·재설치해도 자동 인증된다. 윈도우 값 13~20만원이 사라진다
- 내구성 설계(키보드 방수, 낙하 시험)가 있어 아이가 쓰는 물건에 적합하다
- 기업 리스 반납 물량이 나오면 시세가 매우 낮다

확인할 것은 **배터리 사이클과 열화 정도**다. 3~5년 된 물건이면 교체비 5~10만원을 예산에 잡는다.

**내장그래픽 세대를 본다.** 인텔 10세대 이하의 UHD Graphics는 게임이 힘들다. 11세대 이상 Iris Xe나 라이젠 Radeon이면 훨씬 낫다.

### 게임 노트북을 권하지 않는 경우

중고 게임 노트북은 성능 대비 가격이 놀랍지만, 가정용·아이용으로는 맞지 않는다. 2kg 이상, 팬 소음, 발열, 배터리 1~2시간, 그리고 고부하 사용으로 부품 수명이 짧다.

## 브리프 템플릿

다른 사람에게 공유할 문서를 만들 때 이 구조를 쓴다. 비전문가가 읽을 것을 전제한다.

```markdown
# [대상]용 컴퓨터 구매안

**대상** [사용자, 나이, 용도]
**예산** [금액] ([본체만 / 모니터 포함] 등 범위 명시)
**기준일** [YYYY-MM]

## 먼저 알아두실 것

[시장 상황이 판단을 바꾸는 경우 여기에. 램·SSD 값이 왜 비싼지,
그래서 어떤 전략을 쓰는지. 용어를 풀어서 설명]

## 1안. [성격] — 약 [금액]

| 부품 | 사양 |
|---|---|
| ... | ... |

**되는 것** [실제로 무엇이 가능한지 프로그램 단위로]

**좋은 점**
- ...

**아쉬운 점**
- ...

## 2안. ...

## 3안. ...

## 한눈에 비교

| | 1안 | 2안 | 3안 |
|---|---|---|---|
| 가격 | | | |
| 남는 예산 | | | |
| 지금 체감 성능 | | | |
| 확장 가능성 | | | |

## 이렇게 고르시면 됩니다

**질문 1. [가장 크게 갈리는 조건]?**
→ 예 → **N안**
→ 아니오 → 질문 2로

**질문 2. ...**

[마지막에 기본 추천을 한 단락으로]

## 구매할 때 확인할 것

[비전문가가 놓치기 쉬운 항목. 램 구성, 파워 브랜드, 라이선스 등]

[가격 변동이 심한 시기면 "실제 주문 직전에 다시 확인" 문구를 넣는다]
```

### 템플릿 사용 원칙

**안은 세 개 이하.** 많으면 결정을 못 한다.

**"질문으로 분기" 섹션이 핵심이다.** 표만 주면 비전문가는 고르지 못한다. 가장 크게 갈리는 조건부터 물어 두세 번에 답이 나오게 한다.

**용어를 풀어쓴다.** "PCIe 4.0", "듀얼채널" 같은 말을 쓰지 않고 "나중에 그래픽카드를 넣을 때 여유가 있다"처럼 결과로 설명한다.

**놓치기 쉬운 함정을 명시한다.** 완제품은 램이 한 개로 나오는 경우가 많다는 것, 중고 윈도우는 라이선스가 불분명하다는 것 등. 이 사람이 실제로 구매를 진행할 사람이므로 실무 정보가 필요하다.
