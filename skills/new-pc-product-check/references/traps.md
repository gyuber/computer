# 신품 완제품의 함정

**기준일 2026-11.** 모델 코드 규칙과 CPU 라인업은 해마다 바뀐다. 여기 적힌 규칙과 상품 스펙표가 다르면 **스펙표가 우선**이고, 불일치를 사용자에게 알린다.

## 모델 코드 해독

### LG 그램

예: `16Z90U-GA5xK`

| 자리 | 예 | 의미 |
|---|---|---|
| 앞 숫자 | `16` | 화면 크기(인치) |
| 문자 | `Z` | 일반 노트북, **윈도우 포함** |
| | `ZD` | **OS 미포함** (FreeDOS). 윈도우 값을 따로 더해야 함 |
| | `T` | 360도 회전형(2in1) |
| 숫자 | `90` | **인텔** 그램 |
| | `95` | **AMD 라이젠** 그램 (예: 15Z95U는 라이젠 AI) |
| 끝 문자 | `R` 2023 / `S` 2024 / `T` 2025 / `U` 2026 | 연식 |
| `-` 뒤 | `GA5xK` 등 | 세부 구성(CPU, 램, SSD, 색상). **해독하지 말고 스펙표로 확인** |

`P`가 붙으면 그램 프로 라인이다. 프로가 사무용 프로필에 필수는 아니다.

**SSD 확장 슬롯** — LG 공식 안내 기준 그램은 **모든 모델에 SSD 확장 슬롯이 1개** 있다(서비스센터 장착, 공임 별도). 램은 온보드라 증설 불가. 그래서 "32GB + 512GB"도 SSD는 나중에 늘릴 수 있다. 단 2026-11 기준으로는 32GB + 512GB 모델이 오히려 비싼 프로 라인뿐이라 쓸 일이 없었다. 판정 때마다 가격으로 확인한다.

**32GB + 1TB 구성은 드물다** — 2026-11 기준 그램 중 32GB + 1TB는 15인치 라이젠(`15Z95U-GS59K`, `15Z95U-GU7WK`)과 비싼 그램 프로16 정도였다. 사용자가 "찾기 힘들다"고 하면 다나와 그램 기획전(`plan.danawa.com` 그램가이드)에서 램·SSD 조합으로 찾는다.

**같은 앞자리에 램 16GB/32GB, SSD 256GB/512GB/1TB 구성이 섞여 있다.** 예를 들어 32GB인데 SSD가 256GB인 구성이 실제로 판매된다. 반드시 `-` 뒤까지 포함한 전체 코드로 스펙을 확인한다.

### 삼성 갤럭시북

`NT` + 숫자 + 문자 조합이다. 라인(북, 북 프로, 북 프로 360 등)과 연식은 상품명이 더 정확하다. **램과 SSD는 상세 스펙표에서만 확인한다.**

### 다른 브랜드

레노버, HP, 에이수스, 델은 국내 판매 모델이 해외 모델과 코드가 다른 경우가 많다. 국내 정품 여부와 키보드 각인(한글)을 같이 확인한다.

### 인텔 노트북

| 이름 | 판단 |
|---|---|
| **코어 울트라 시리즈 3** (2026년형) | 최신. 문제없음 |
| **코어 울트라 200V** (예: 226V, 258V) | 저전력, 배터리 우수. **램이 CPU에 붙어 있음** (아래 참고) |
| **코어 울트라 200H·200U** | 문제없음. H는 고성능이라 무겁고 배터리가 짧은 편 |
| 코어 울트라 100 시리즈 (1세대) | 쓸 만하나 연식이 있음. 가격이 확실히 싸야 함 |
| **코어 5·7 (울트라가 없는 것)** 예: 코어 5 120U, 코어 7 150U | **구형 13세대 기반 리브랜드.** 이름에 속기 쉬움. 사무용으로 작동은 하나 신품 가격이면 감점, 업무용 장기 사용 프로필이면 탈락 |
| i3, 셀러론, 펜티엄, N100·N150·N200 등 N시리즈 | 저가형. 업무용 탈락 |

| 이름 | 판단 |
|---|---|
| **라이젠 AI 5·7·9 (300 시리즈 이후)** | 최신. 문제없음 |
| 라이젠 200 시리즈 (예: 라이젠 5 220) | 직전 세대 리브랜드. 쓸 만함 |

| 라이젠 7000번대 노트북 (예: 7530U, 7520U) | **세 번째 숫자가 아키텍처.** 7**5**30U는 2021년 설계, 7**2**0U대는 더 오래됨. 신품 가격이면 감점 |
| 라이젠 3 | 업무용 탈락 |

### 데스크탑

| CPU | 내장그래픽 |
|---|---|
| 인텔 이름 끝 `F`, `KF` (예: 14400F) | **없음.** 그래픽카드가 없으면 화면이 안 나옴 |
| 라이젠 5000번대 이하에서 `G`·`GT` 없음 (5600, 5600X 등) | **없음** |
| 라이젠 7000·9000번대에서 `G` 없음 (7600, 9600 등) | 있음. 화면 출력·사무용은 되나 게임은 불가 |
| 라이젠 `G` (8500G, 8600G 등) | 있음. 라이트 게임까지 |

## 램 구성

### 노트북: 온보드가 기본이다

얇은 노트북 대부분은 램이 기판에 납땜돼 있다. **산 용량이 끝까지 간다.** 스펙표에 "온보드", "교체 불가", "슬롯 없음"이 있으면 증설 불가로 판단한다. 표기가 없으면 증설 불가로 가정하고 확인 항목에 넣는다.

### 코어 울트라 200V의 램

200V는 램이 CPU 패키지 안에 있어서 **CPU 모델이 곧 램 용량**이다. 일반적으로 모델 번호 끝자리가 `6`이면 16GB, `8`이면 32GB다(예: 256V는 16GB, 258V는 32GB). 32GB가 필요한 프로필이면 끝자리 `8` 모델만 후보다. 스펙표로 최종 확인한다.

### 데스크탑: 한 개인지 두 개인지

완제품은 16GB를 8GB×2로 넣는 경우가 많다. 나중에 32GB로 가려면 둘 다 버려야 한다. 16GB×1에 빈 슬롯이 있는 구성이 증설에 유리하다. 내장그래픽만 쓰면 듀얼채널(2개)이 성능에 유리하므로, 프로필의 우선순위로 판단한다.

## 가격 착시

| 착시 | 확인 방법 |
|---|---|
| OS 미포함 (그램 `ZD`, "프리도스") | 윈도우 값을 더한 실질 총액으로 비교 |
| Windows Home | 프로필이 Pro를 요구하면 Pro 업그레이드 값을 검색해 가산 |
| "최대 혜택가" | 특정 카드 + 쿠폰 + 멤버십이 겹친 값. 조건을 분리해서 적음 |
| 사은품 | 마우스, 파우치 등은 가격 판단에 넣지 않음 |
| 오피스·한글 "포함" | 체험판인지 영구 라이선스인지 확인 |
| 같은 이름, 다른 구성 | 전체 모델 코드로 최저가 비교 |
| 작년 모델 재고 | 연식 문자로 확인. 싸면 오히려 좋은 선택일 수 있음. 가격 차이가 세대 차이만큼 나는지 판단 |
| **"싸게 잘 나온다"는 기본 구성** | 60~90만원대 조립·완제품은 대개 16GB(또는 8GB), 512GB, OS 없음, 무명 파워다. 프로필 조건(32GB, 1TB, OS)을 맞춘 **총액**으로 비교하면 40~70만원이 붙는다 |
| 정가 부풀리기 | "정가 187만 → 109만" 같은 큰 할인 표기. 판매가로만 비교 |
| 판매처 OS 옵션 | 샵다나와 기준 Home +20.5만, Pro +34.5만 (2026-11). Windows FPP를 따로 사면 Home 약 12~17.5만으로 더 쌀 수 있음 |
| 판매처 32GB 옵션 | 16GB→32GB 옵션이 +18~22만. 직접 조립 시 삼성 DDR4 16GB 약 17~19만 × 2 |

### 32GB를 싸게 맞추는 경로

데스크탑이고 관리하는 사람이 직접 손볼 수 있으면, **16GB 완제품 + 16GB 직접 추가**가 판매처 32GB 옵션보다 쌀 수 있다. 조건이 있다.

- 기존 램이 **16GB×1**이어야 한다 (8GB×2면 슬롯이 없음)
- 기존 램 제조사·모델을 확인해 같은 것으로 맞춘다 (DDR4는 비교적 관대, DDR5는 섞으면 위험)
- 이 경로로 싼 무명 부품 완제품을 고르면 프로필의 "좋은 부품" 기준과 충돌한다. 부품 등급이 우선이다

### 직접 조립 견적을 기준선으로 쓴다

조립·수리를 할 수 있는 사용자면 **통과 등급 부품으로 직접 조립한 견적**을 먼저 뽑아 기준선으로 둔다. 판매처 조립PC나 완제품은 "이 기준선보다 비싼 만큼의 값(조립·보증·AS)을 하는가"로만 판단한다. 부품 등급은 `used-pc-listing-check/references/part-tiers.md`를 쓴다.

## 판매 경로

| 경로 | 판단 |
|---|---|
| 국내 정품 (공식몰, 대형 오픈마켓의 정식 판매처) | 기준 |
| 전시·개봉·리퍼 | 보증 기간이 새 제품과 같은지 확인. 같으면 좋은 선택 |
| **구성변경상품** (다나와 표기) | 판매처가 개봉해 램·SSD를 바꾼 제품. **32GB 기업용 데스크탑(레노버·HP)은 대부분 이것**이다. 제조사 정식 보증·출장 AS가 유지되는지 판매처에 확인. 유지 안 되면 브랜드 PC를 사는 이유가 줄어든다 |
| 해외직구·병행수입 | 국내 AS가 안 되거나 유상인 경우가 많음. 영문 키보드. 업무용 탈락 |

판매자가 "정품"이라고만 적고 국내 정식 수입인지 밝히지 않으면 확인 항목에 넣는다.

## 단자와 모니터 연결

사무실에서 모니터에 꽂아 쓰는 프로필은 **USB-C 하나로 화면과 충전이 되는지**를 본다.

| 표기 | 의미 |
|---|---|
| 썬더볼트 4·5 | 화면 출력 + 충전 + 고속 데이터. 가장 좋음 |
| USB-C (DP Alt Mode, PD 지원) | 화면 출력 + 충전. 충분함 |
| USB-C (데이터 전용) | 화면 출력 안 됨. 감점 |

모니터 쪽도 USB-C 입력과 충전 출력(65W 이상 권장)을 지원해야 케이블 하나로 끝난다. 노트북과 모니터를 같이 검토할 때 짝을 맞춘다.

## 일체형 PC

본체가 모니터 안에 들어간 형태. 국내에는 저가 일체형 전문 브랜드(예: 디클 = 디지탈클릭)가 있고, 사용자 주변에서 "최고급"으로 언급되기도 한다.

| 확인할 것 | 이유 |
|---|---|
| CPU 세대 | "i7"이라도 몇 세대 전인 경우가 많다 (2026-11 디클 최상위 A24-712는 i7-12700) |
| 화면 | 23.8인치 FHD가 흔하다. 업무용 27인치 QHD보다 작다 |
| OS 에디션, AS 기간·방식 | 상세 페이지에 없는 경우가 많다. 1년 택배 AS가 흔하다 |
| 정가 표기 | 정가를 부풀린 대폭 할인 표기가 흔하다 |
| 고장 구조 | 화면과 본체가 한 몸이라 한쪽이 고장 나면 둘 다 멈춘다 |

노트북을 함께 쓰는 사용자에게는 역할이 겹치고 파일이 나뉜다. 대안은 **노트북 + USB-C 충전 모니터**다.

## 검색 범위

- **다나와**: 검색 결과·상품 페이지·샵다나와 조립PC 페이지를 읽을 수 있다. 같은 모델의 "다른 구성"은 펼쳐지지 않으므로, 원하는 구성이 안 보이면 다른 검색어로 다시 찾는다
- **컴퓨존**: 검색·목록 페이지는 스크립트로 상품을 불러와서 자동 수집이 안 된다. **상품 상세 링크를 사용자에게 받아** 검토한다
- 판정에 쓴 범위를 답에 밝힌다. 다나와만 봤으면 "다나와 기준"이라고 쓴다. 사용자가 "여기서 이게 제일 낫냐"고 물으면 전수 조사가 아니었다는 점을 먼저 말한다
- 모르는 브랜드·제품명(예: "디클")은 다나와 통합검색으로 브랜드부터 확인한다. 일반 웹 검색은 엉뚱한 결과(델 등)로 빠지기 쉽다
