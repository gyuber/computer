# 사용자 프로필

판정 기준은 사람마다 다르다. 여기 있는 프로필을 쓰고, 새로운 사람이 생기면 같은 형식으로 추가한다.

**공개 저장소에 둘 수 있는 내용만 쓴다.** 이름, 직장, 연락처, 의뢰인 정보 같은 것은 쓰지 않는다.

## 업무용 PC (변호사)

**결정 근거와 경과** — 추적 이슈 `gyuber/computer#3`. 판정 결과는 이 이슈에 코멘트로 남긴다. 기준일 2026-11.

**형태는 미확정이다.** 데스크탑과 노트북을 둘 다 후보로 본다. 들어온 상품의 형태에 맞는 기준표를 쓴다. **사용자가 "정했다"고 말하기 전에는 이슈나 답변에 "결정"이라고 쓰지 않는다.** "이게 맞을 것 같다"는 동의이지 결정이 아니다.

**용도**
- 서면 작성 (한글, 워드), 엑셀, 사건 기록 PDF와 스캔본 검토
- Claude Code (Windows 데스크톱 앱). 추론은 클라우드에서 돌아가므로 로컬 부담은 여러 프로그램을 동시에 띄우는 데서 온다
- 사무실과 외부(법원, 미팅) 모두에서 작업한다

**최우선 기준: 업무하는 데 불편함이 없을 것.** 성능이 아니라 버벅임 없음, 고장 시 빨리 복구, 파일 관리의 단순함을 뜻한다.

**관리하는 사람** 동생이 PC를 직접 조립·수리할 수 있다. 그래서 **제조사 출장 AS나 기업용 라인은 필수가 아니고, 조립PC를 허용한다.** 대신 부품은 `used-pc-listing-check/references/part-tiers.md`의 **통과 등급 이상**만 쓴다. 기업용 브랜드에 가산점을 주던 이유(AS 창구 하나)가 사라졌다.

**구매 방식** 신품. 완제품, 판매처 조립PC, 직접 조립 모두 가능

**우선순위**

| 순위 | 항목 | 이유 |
|---|---|---|
| 1 | **램 32GB** | 노트북·데스크탑 모두 필수. 노트북은 증설 불가라서, 데스크탑은 사용자가 32GB를 원해서 |
| 2 | 부품 신뢰도·수리 용이성 | 통과 등급 부품. 조립이면 부품 모델명이 모두 공개된 것 |
| 3 | SSD 1TB | 스캔 PDF가 쌓임 |
| 4 | OS | Win11. 노트북은 Pro(BitLocker) 강하게 권장, 데스크탑은 Home 허용 |
| 5 | CPU | 5급이면 충분 |
| 6 | 그래픽 | **최하위.** 내장그래픽으로 모니터 출력만 되면 됨. 내장그래픽 성능을 장점으로 내세우지 않는다 |

**예산**

| | 데스크탑 | 노트북 |
|---|---|---|
| 상한 | **150만원 이하** (본체 + OS, 모니터 별도) | 명시 없음. 약 240~290만원대 검토 |

**두 형태의 갈림길**

| | 데스크탑 + 모니터 | 노트북 + 사무실 모니터 |
|---|---|---|
| 외부 작업 | 별도 기기 필요 | 그대로 들고 감 |
| 램 증설 | 가능 | 대부분 불가 (32GB로 사야 함) |
| 작업 폴더 | 외부 기기와 나뉨 → 클라우드 동기화 필요 | 한 곳 (Claude Code가 로컬 폴더 기준이라 중요) |
| 분실 위험 | 낮음 | 있음 → 디스크 암호화 중요 |
| 이 업무에서 성능 | 차이 없음 | 차이 없음 |

성능으로 가르지 않는다. **휴대 여부와 가격**으로 가른다.

**공통 기준**

| 항목 | 필수 | 감점 | 탈락 |
|---|---|---|---|
| 램 | **32GB** | — | 32GB 미만 (데스크탑은 16GB×1 + 직접 추가 경로가 확실할 때만 예외) |
| OS | Windows 11 | 노트북 Home (Pro 업그레이드 비용 가산) | 맥 (한글), OS 미포함인데 총액 비교 안 함 |
| SSD | 1TB NVMe | 512GB | **256GB 이하** |
| CPU 등급 | 5급 이상 | 오버스펙 (i7·i9, 라이젠 7·9 데스크탑, H·HX 노트북) | 3급 이하, 구형 리브랜드 |
| 그래픽 | 내장 | 외장 RTX (오버스펙) | 내장그래픽 없는 CPU에 카드도 없음 |
| 판매 경로 | 국내 정품 | 전시·리퍼, 구성변경상품 (보증 확인) | 해외직구·병행수입 |
| 형태 | — | — | **일체형** (아래 참고) |

### 데스크탑 기준

| 항목 | 필수 | 감점 | 탈락 |
|---|---|---|---|
| CPU | 라이젠 5600GT·5500GT (AM4) 우선. 라이젠 8500G·8600G, i5 13·14세대, 코어 울트라 5도 가능 | 인텔 `F` + 그래픽카드 (오버스펙) | 라이젠 5000번대 이하 G 없는 모델·인텔 `F`인데 그래픽카드 없음 |
| 램 | 32GB (DDR4 16GB×2 등) | — | 32GB 미만 |
| 메인보드 | B550 (A520도 APU면 손실 없음) | — | A320·B350 |
| 파워 | part-tiers 통과 브랜드 | — | 브랜드 미표기 |
| 부품 공개 | 모든 부품 모델명 공개 | 일부 미기재 (판매처 확인 후 판단) | 파워·보드·램·SSD 전부 미기재 |
| 예산 | 150만원 이하 | — | 초과 |

**AM4(5000번대 G)를 우선하는 이유** — 32GB가 필수가 되면서 램 값 차이가 그대로 총액 차이가 된다. DDR4가 DDR5보다 훨씬 싸다(2026-09 앵커: 32GB DDR4 약 38만원, DDR5 약 70만원). 사무용은 CPU 교체가 필요 없어 AM4 단종은 문제가 아니다. **재검토 조건**: 램 값이 정상화돼 DDR4·DDR5 차이가 작아지면 AM5를 다시 본다. 판정할 때 램 시세를 검색해 전제를 확인한다.

**기준선 견적 (2026-11-17, 직접 조립)** — 이보다 비싸고 나을 게 없으면 탈락

| 부품 | 제품 | 가격 |
|---|---|---|
| CPU | 라이젠5 5600GT 정품 (쿨러 포함) | 약 28.9만 |
| 메인보드 | MSI B550M-A PRO | 약 9.6만 |
| 램 | 삼성 DDR4-3200 16GB × 2 | 약 38.8만 |
| SSD | 삼성 990 EVO Plus 1TB | 약 32.2만 |
| 파워 | 마이크로닉스 Classic II 풀체인지 600W 80PLUS 실버 | 약 6.4만 |
| 케이스 | mATX (미선정) | 약 5만 (가정) |
| OS | Windows 11 Home FPP | 약 11.9~17.5만 |
| **합계** | | **약 133~138만** |

같은 조건(32GB, 1TB, OS)을 맞추면 판매처 조립PC는 약 153~162만, 기업용 브랜드 32GB는 약 155~175만이었다. 가격은 판정할 때마다 다시 검색한다.

### 노트북 기준

| 항목 | 필수 | 감점 | 탈락 |
|---|---|---|---|
| 램 | **32GB** | — | 32GB 미만 (온보드라 증설 불가) |
| SSD | 1TB, 또는 512GB + 빈 확장 슬롯 | 512GB (슬롯 없음) | 256GB 이하 |
| CPU | 인텔 코어 울트라 5·7, 라이젠 AI 5·7 | H·HX 고성능 (무게·배터리) | 울트라 아닌 코어 5·7 리브랜드, 노트북용 라이젠 5000번대 |
| 화면 | 14~16인치 | 17인치 (휴대 부담) | — |
| 무게 | 1.3kg 이하 | 1.3~1.6kg | 2kg 이상 |
| 단자 | USB-C로 화면 출력 + 충전 (썬더볼트 또는 DP Alt + PD) | 화면 출력은 되나 충전 안 됨 | — |
| 보안 | BitLocker (Pro), 지문 또는 얼굴 인식 | 생체 인증 없음 | — |

**2026-11-17 기준 1순위** LG 그램15 15Z95U-GS59K (라이젠 AI 5 435, 32GB, 1TB, 1.29kg, Win11 Home, 약 243만). 32GB + 1TB 그램은 사실상 15인치 라이젠(`Z95`) 두 모델뿐이었다. AI 7 모델(GU7WK)은 이 업무에서 체감 차이가 없어 2순위.

### 일체형을 탈락시키는 이유

사용자 주변에서 "최고급 일체형"(예: 디클 올인원 i7 모델) 이야기가 나올 수 있다. 이 프로필에서는 탈락이다.

- 노트북을 사면 역할이 겹치고, 둘 다 사면 작업 폴더가 갈라진다
- 화면과 본체가 한 몸이라 한쪽이 고장 나면 둘 다 멈춘다
- "최고급"의 실체가 몇 세대 전 i7인 경우가 많고, 이 업무에서 체감이 없다
- 정가를 부풀리고 큰 폭 할인으로 보이게 하는 표기가 흔하다

깔끔한 책상을 원하는 것이면 **노트북 + USB-C 충전 모니터**(케이블 하나로 화면·충전·주변기기)를 대안으로 제시한다.

**이 프로필에서 중요한 것**
- 노트북이면 분실 시 디스크 암호화(BitLocker)가 실질적 차이다. Pro가 아니면 업그레이드 비용을 실질 총액에 넣는다
- 데스크탑으로 가면 외부 작업용 기기와 파일이 나뉜다. 판정할 때 한 줄 언급한다
- 사용자가 기준을 자주 갱신한다(16GB → 32GB, 기업용 → 조립 허용, 예산 상한 추가). 바뀔 때마다 이 프로필과 추적 이슈 본문을 같이 고친다

## 아이용 데스크탑 (초등학생)

이 프로필의 결정은 중고 매물 검토 과정에서 이미 내려졌다. 상세 판단 틀은 `pc-buying-brief`, 매물 판단은 `used-pc-listing-check`에 있다. 신품 완제품이 후보로 들어오면 이 기준으로 본다.

**용도** 문서, 웹, 영상 시청, 교육용 프로그래밍, 라이트 게임(마인크래프트). 방에 두는 물건이라 소음과 발열이 중요하다

| 항목 | 필수 | 감점 | 탈락 |
|---|---|---|---|
| CPU | 6코어 12스레드 (라이젠 5 G, i5) | 8코어 이상 (오버스펙) | 6코어 6스레드, 3급 이하 |
| 램 | 16GB, 빈 슬롯 | 8GB×2 (나중에 둘 다 교체) | 8GB 이하 |
| SSD | 500GB 이상 NVMe | — | 256GB 이하 |
| 그래픽 | 내장 또는 저전력 중급 | 200W 이상 카드 | 내장그래픽 없는 CPU에 카드도 없음 |
| 파워 | 브랜드 명시 | — | 브랜드 미표기 |

## 새 프로필 형식

```markdown
## [용도] ([사용자 역할])

**결정 근거와 경과** — 추적 이슈 (있으면)

**용도** 프로그램 단위로. 휴대 여부, 사용 장소

**구매 방식** 신품/중고, 선호 라인

**예산 감각** 금액과 기준일

| 항목 | 필수 | 감점 | 탈락 |
|---|---|---|---|

**이 프로필에서 중요한 것** 다른 프로필과 판단이 갈리는 지점 한두 개
```

프로필이 정해지기 전이면 `pc-buying-brief`로 방향부터 정한다.
